# IPL Score Prediction

## Author
Arsh

## Project Description
This project predicts the first innings score of IPL matches using
machine learning regression models. Historical IPL data is used
for training and prediction.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## How to Run
1. Clone the repository
2. Install required libraries
3. Run the Jupyter Notebook
